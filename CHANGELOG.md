# Changelog

All notable changes to Pako are documented here.

## [Unreleased]

- Continued beta hardening and lifecycle coverage.

## [0.1.0-beta.1]

- User-space installation with atomic activation and rollback.
- Signed TUF catalog and metadata verification.
- External upstream archives and TUF-hosted package archives.
- SHA-256 artifact cache with integrity checks.
- Complete tree verification before activation.
- Beta limitations: no runtime sandbox, delta updates, or background updates.
